# Demo Video Script (under 3 minutes)

Lead with the result — judges are not required to watch past 3 minutes.

## 0:00–0:20 — The result, first
An alert firing: felt (vibration) and seen (context card), before any setup or architecture talk.

## 0:20–1:30 — Live walkthrough
A real event happening → Signal Score/Class visibly computed → the multi-channel alert landing on the companion app. Show the actual numbers, not a mockup.

## 1:30–2:20 — Architecture flash
Ring → Bedrock/AgentCore → companion app. Enough to prove Tech Implementation without narrating every file.

## 2:20–3:00 — Impact + close
Who this serves beyond the hackathon (deaf/hard-of-hearing/DeafBlind Ring users); strong closing line.

## Shot list
- [ ] Screen recording: live event → alert (primary shot, used at 0:00)
- [ ] Screen recording: Signal Score breakdown visible
- [ ] Screen recording or diagram: architecture flash
- [ ] Voiceover or captions covering impact framing
